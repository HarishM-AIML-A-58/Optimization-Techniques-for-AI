# Optimization Techniques for AI – Lab Record

Welcome to the lab record for **Optimization Techniques for AI**. This repository contains implementations, analysis, and documentation of key optimization techniques that are essential in Artificial Intelligence and Machine Learning.

## 🔍 Subject Overview

The objective of this lab is to provide hands-on experience with fundamental optimization problems and methods used in AI. These methods enable efficient problem-solving in areas such as resource allocation, project planning, model training, and combinatorial optimization.

---

## 📘 Lab Topics Covered

### 1. Transportation Problem
- Formulation and solution of supply-demand problems.
- Cost minimization strategies using methods like Vogel's Approximation and MODI.

### 2. Assignment Problem
- Optimal task assignment to agents using the Hungarian Algorithm.
- Application to job scheduling and resource planning.

### 3. Critical Path Method (CPM) – Analysis
- Network modeling for project management.
- Identification of the longest path determining project duration.

### 4. Project Evaluation and Review Technique (PERT) – Analysis
- Probabilistic time estimation.
- Calculation of expected project time and variance.

### 5. Linear Programming Problem – Constraint Optimization
- Maximization/Minimization of objectives with linear constraints.
- Solved using graphical and simplex methods.

### 6. Integer Programming – Branch and Bound Method
- Optimization with integer-only solutions.
- Applications in discrete decision-making.

### 7. Dynamic Programming
- **Knapsack Problem**: Optimal subset selection to maximize profit.
- **Subset Sum Problem**: Decision problem for achieving exact target sums.
- **Longest Common Subsequence (LCS)**: Finding the longest shared subsequence in strings.

### 8. Gradient Descent Method – Stochastic Gradient Descent (SGD)
- Optimization of loss functions in ML.
- Parameter updates using mini-batches of data.

### 9. Unconstrained Optimization – Non-Linear Least Squares
- Curve fitting and regression model optimization.
- Gauss-Newton and Levenberg-Marquardt methods.

### 10. Kuhn–Tucker Conditions – Lagrangian Multiplier Method
- Solving constrained non-linear optimization problems.
- First-order necessary conditions for optimality.

---

## 🧠 Learning Outcomes

By the end of this lab, students will be able to:
- Model real-world problems using mathematical optimization techniques.
- Apply both classical and AI-specific optimization algorithms.
- Analyze, interpret, and implement optimization strategies effectively.
